# CyberScan Architecture Decisions

## Decision 001 Project name

CyberScan is the current product name. ThreatGraph is the previous working name and remains useful when referring to the security-graph concept.

## Decision 002 Evidence providers

CyberScan integrates specialist scanners instead of replacing them. Scanners provide evidence; CyberScan normalizes, correlates, prioritizes, and explains that evidence.

## Decision 003 Incremental delivery

CyberScan will be built as vertical slices. A working evidence pipeline has priority over a broad but unverified platform surface.
